# Manual accessibility checks: original site

## Method
- Tested index, enquiry and about pages on the original site by myself
- Setup: Google Chrome on macOS, used locally with the VS Code Live Server extension
- Checks: keyboard only navigation and zoomed in to 400%

## Issues occured on all pages
- Scroll bar still visible on 400% zoom, meaning you can't see the full site when zoomed
- Tab begins on home, meaning users have to tab through the navigation on each page, this could be fixed with a skip link


## Index page
- Tabbing skips over a SUV, making it misleading to view more information / open an enquiry about it
- "Ask about this car" appears to be unvisitable, when really it's clickable with mouse

## Enquiry page
- No confirmation page after submitting a filled form
- No error page after submitting an unfilled / empty form

## About page
- Header is worded and ordered differently, could be confusing for users
